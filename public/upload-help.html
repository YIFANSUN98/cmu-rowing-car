Download your files, then upload here

Download each formatted Google Sheet as an Excel file. The website reads the files locally; no Drive connection setup is needed. Sign in as admin to plan with TomTom. Planning saves the Excel originals privately for admins; Publish to team shares only route details.

  1. Open your example folder: week 1, week 3, or week 4, or week 5. Sign into Google to access your private folders.
  2. Open each of the three Sheets: members, attendance, and drivers.
  3. In each Sheet choose File → Download → Microsoft Excel (.xlsx).
  4. Return to Launch, click Choose Excel files, and select all three downloads together, or drag and drop them together. Members, Attendance, and Drivers are detected automatically. Only .xlsx is accepted.
  5. Resolve any data review checks, then click Plan week to calculate using TomTom online estimates. After changing your Sheets, download again and reupload. Replan to update any stale result.

Past weeks keep their original dates and use matching future weekdays for labeled traffic comparisons.

Simple sheets for members

  • Members: Name, Pickup address
  • Attendance: Names down column A, dates across row 1, Yes/No in the grid
  • Drivers: Names down column A, dates across row 1, Yes/No in the grid

Use the same name in every sheet and choose values from the dropdowns. No member IDs are needed. Give different people distinct names. Pickup addresses are used directly, and everyone marked attending needs a carpool seat unless marked in an optional travel tab. Both grids offer Yes or No only. Empty uploaded answers default to No in both grids. A Yes driver uses five total seats, including the driver. There is no Seats column.

Keep Attendance as Yes/No. Optional Own travel and Uber tabs in that same workbook use the same grid: Yes marks an independent trip or a required Uber. Those members must also be Yes in Attendance. When club cars lack seats, the planner proposes Uber groups automatically. Uber rides need a separate booking.

Use the three formatted example Sheets, with template column names in row 1. The old historical car-assignment layouts need review and conversion first. Keep the date-grid tab names Attendance and Drivers so the uploader can identify them. Filenames do not matter. A workbook containing all three tables can be selected once. Select files from the same week; duplicate tables are rejected. You can also select one replacement file in the same upload area. Hidden archive tabs preserve the original data and are ignored during upload. Edit the visible simple table.

Excel date/time cells and TRUE/FALSE cells are supported. If using text, keep dates as YYYY-MM-DD and times as HH:MM. Formula cells need saved results; the app does not calculate formulas. Remove merged cells and fix spreadsheet errors before downloading.

Each file must be smaller than 5 MB. The Excel input table must fit within 10,000 rows and 100 columns. Resolve unknown attendance and missing pickup addresses, check practice dates, and collect actual driver availability before a real schedule. Car cards show driver and riders; Show route expands the route.
